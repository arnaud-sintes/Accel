Vendored, offline-only third-party assets for P2-T5's WebView2-hosted terminal (App/Controls/TerminalView).
No CDN reference and no npm-at-build-time dependency: these are the actual npm-published dist
files, downloaded once and committed here, at pinned versions.

xterm.js
  Package:  @xterm/xterm
  Version:  5.5.0
  File:     xterm.js       (lib/xterm.js  - UMD bundle, exposes window.Terminal)
  File:     xterm.css      (css/xterm.css)
  License:  MIT
  Source:   https://www.npmjs.com/package/@xterm/xterm/v/5.5.0

xterm-addon-fit
  Package:  @xterm/addon-fit
  Version:  0.11.0
  File:     addon-fit.js   (lib/addon-fit.js - UMD bundle, exposes window.FitAddon)
  License:  MIT
  Source:   https://www.npmjs.com/package/@xterm/addon-fit/v/0.11.0

xterm-addon-webgl
  Package:  @xterm/addon-webgl
  Version:  0.18.0 (the release matching @xterm/xterm 5.5.0, and like it still a UMD bundle)
  File:     addon-webgl.js (lib/addon-webgl.js - UMD bundle, exposes window.WebglAddon)
  License:  MIT
  Source:   https://www.npmjs.com/package/@xterm/addon-webgl/v/0.18.0

Note on version choice: @xterm/xterm 6.0.0 (latest at the time of writing) dropped the classic
lib/xterm.js UMD bundle from its published package (CJS/ESM module entry points only), which
does not work as a plain <script> tag inside the offline-served WebView2 page below. 5.5.0 is
the newest release that still ships that UMD bundle, so it (and the matching 0.11.0 addon-fit,
itself UMD) is what's vendored here instead.

index.html is Accel's own file (not vendored), gluing the two together with no live PTY behind
it - see TerminalView.xaml.cs's doc comment for the full P2-T5/P2-T5b split.
